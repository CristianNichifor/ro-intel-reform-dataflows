# 06 · Glosarul termenilor fluxurilor de date

| Termen | Definiție |
| --- | --- |
| **Token de mandat** | Autorizație criptografică emisă de SSC care leagă o cerere de date de un temei legal |
| **IADE** | Schimb de date interinstituțional — broker fără stare + registru de audit |
| **Vault de caz** | Stocare criptată specifică agenției pentru dosarele de caz |
| **Filtru de minimizare** | Proces automatizat care elimină datele personale irelevante înainte de transfer |
| **Registru de audit** | Jurnal append-only, înlănțuit prin hash-uri, al tuturor tranzacțiilor de fluxuri de date |
| **Verificare dublă** | Validarea de către SSC atât a temeiului legal, cât și a specificității cererii |
| **Handshake** | Ciclul cerere–token–rutare–răspuns între agenții prin IADE |
| **Temei** | Categoria statutară de amenințare la securitatea națională care justifică un mandat |
| **Hash de lanț de custodie** | Dovadă criptografică care leagă probele de înregistrările din registrul de audit |
