# 06 · Glossary of Data-Flow Terms

| Term | Definition |
| --- | --- |
| **Warrant Token** | Cryptographic authorization issued by SSC binding a data request to a legal predicate |
| **IADE** | Inter-Agency Data Exchange — stateless broker + audit ledger |
| **Case Vault** | Agency-specific encrypted storage for case files |
| **Minimization Filter** | Automated process removing irrelevant personal data before transfer |
| **Audit Ledger** | Append-only, hash-chained log of all data-flow transactions |
| **Double-Check** | SSC validation of both the legal predicate and the specificity of the request |
| **Handshake** | Request–token–route–response cycle between agencies via IADE |
| **Predicate** | Statutory national security threat category justifying a warrant |
| **Chain-of-Custody Hash** | Cryptographic proof linking evidence to its audit ledger entries |
